## 识别结果

- A 表：雇员 3,555 行、3,555 个非空不同编号。仅 v2 为 387 行，仅 v3 为 3,168 行，两条路径重叠为零；v2 仅有 1 条物价答案，v3 的四题有效数依次为 5、0、8、2。经营者 9,354 行、9,353 个不同编号，全部匹配。补充表有 14,876 行、14,874 个不同编号，只有 2 个编号重复，共涉及 4 行。
- B/D 表：雇员和经营者四题的所有非空答案均可编码。没有观察到不确定／不适用、字典外选项或数值冲突导致失效。六项与 11061530 的对照全部 MATCH，首个可见差异为 none。
- C 表：逐题看，雇员只有 11/3,555 条有明确关注标记（0.31%），经营者有 4,590/9,354 条（49.07%）；逐题缺关注标记的两组均无有效答案。每题人数相同，不足以断定跨题是完全相同的人。missing 也不同于明确未选。
- 房价只在经营者选中关注者中出现（589 条中有效 483 条）；雇员无人选中关注房价。利率在两组选中者中分别有 2/2、702/892 条有效，未选者为零。但 GDP 和物价在未选者中也有有效答案：雇员分别为 3 和 5 条，经营者为 1,975 和 1,495 条。因此，不能把四题统一解释为“仅关注才作答”。

## 对研究的含义

沿用当前补充表，改答案字典、放宽时长或减少控制变量都无法补回已经为空的原字段。雇员的 Q2 房价完全不可估，其他宏观题也无法支持单季推断；雇员回归的预期证据应按后四波为主来解释。若要恢复 Q2，优先核对补充问卷实际发放对象、分题跳转和补充答案如何写入平台表；本地 4,604 个 seqno 与平台 submit_id 的对应关系仍待确认。
