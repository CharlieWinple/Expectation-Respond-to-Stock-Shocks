## 样本与识别边界

- 100 秒含下限，缺失时长保留。五波起始 14,371 条，经时长筛选余 10,677 条，剔除 3,694 条（25.70%）；这是五波全体雇员口径，与此前共同四波 B 样本的插值分母不同。去重后 10,671 条，Cell 合格 10,213 条，控制完整 8,329 条。教育缺失 1,808 条，是完整案例损失的主要来源。
- BASE 的 8,329 条包括正持仓 4,401 条、记录为零 223 条、未匹配按零处理 3,705 条。被动收益中位数为零，标准差 0.1419 万元。每万元系数的单位明显大于样本中典型的收益变动。
- 2024Q2 补充表匹配 3,555/3,555 条，但 GDP、房价、物价、利率分别只有 5、0、9、2 条有效答案；逐题共同样本只贡献 1、0、3、0 条。股票当波无题。五项估计实际上几乎全部来自后四波。报告未细分缺失、冲突和不确定答案，不能仅凭匹配率判断问卷覆盖。
- BASE 及五个结果样本的 Cell 平衡表均为 10 个可检验特征中 0 个原始 p<.05，第 11 项为常数。各结果样本最大绝对标准化系数为 0.02353–0.03101。同期可观测特征的关联较弱，仍须考虑未观测差异、完整案例选择及按零处理的未匹配持仓。
- 另需区分基金收益构造风险。项目已有基金公告核验记录，历史折算与分红可能影响部分基金的收益和可用性；本报告无法量化其对雇员估计的影响。
