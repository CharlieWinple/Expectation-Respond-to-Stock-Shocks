# 净值收益标注版：保留数值，默认不筛除

2026-10-13 用户明确选择：主收益列保留可计算的未筛查收益，另加标记，平台默认不按疑似事件筛除。本版替代筛查版作为当前平台输入；旧文件保留。

## 数值和标记分开

普通基金主收益仍为 `NAV_end/NAV_base-1`，不对分红和折算进行调整。只要两个端点均为有限正数，就保留其计算结果。这里的“未筛查收益”不是 CSMAR 的原累计净值收益率；后者另保留在 original 字段。

- `raw_return` 与主收益列数值相同，保留未筛查的净值价格收益。
- `screened_return` 保留上一版筛查后数值，仅供比较。
- `return_calculable` 表示收益有值；普通基金的 `shock_usable` / `ctrl_usable` 现在同样表示可计算，**不代表质量合格**。
- `screen_pass_all_checks` 才是上一版所有质量条件是否通过。
- 各个 `flag_*` 为独立标记，可重叠。净值关系和日跳变标记：1=触发，0=未触发，空=不能判断或不适用（货币基金）。不能将空值解释为没有问题。

缺少有效端点的普通基金收益仍为空，不补零、不推算。货币基金主收益和可用状态完整保留原政策，未解决的货币收益也不恢复为候选值。

## 标记标准

设 N 为单位净值、A 为累计净值，0 为窗口基准日。

| 标记 | 触发标准 | 含义 |
| --- | --- | --- |
| flag_nav_relation_break | 窗口内既不能维持 `A_t-N_t=A_0-N_0`，也不能维持 `A_t=(A_0/N_0)N_t` | 疑似事件或无法解释的净值构造，不等于事件确认 |
| flag_large_daily_jump | 相邻净值比值 >1.25 或 <0.8 | 大跳变，可能来自折算或真实涨跌 |
| flag_daily_evidence_insufficient | 无日度筛查数据、有效日覆盖<80%、内部缺至少一个推断交易日、日/月终点不符或日净值无效 | 证据不足，不直接指认为事件 |
| flag_window_return_large | 月度绝对收益>50%，或短 shock 绝对收益>20% | 原有幅度审查阈值，不自动剔除 |
| flag_date_or_inception | 端点过旧/缺失、成立时间不满足窗口、前月引用不符 | 日期或口径需核对 |
| flag_currency | 非人民币、未作汇率转换 | 原币净值增长率，不代表人民币投资收益 |
| flag_legacy_issue | 原有补丁仍记录未解决问题 | 保留历史问题线索 |

两种净值关系要求至少一种贯穿整个窗口，不是每天任选一种。容差沿用筛查版：字段需要第四位小数时步长取 0.0001，否则 0.001；加法残差容差 `1.05*(eps_A+eps_N)`，乘法残差容差 `1.05*(eps_A+abs(A_0/N_0)*eps_N)`。若两字段均为四位小数，加法容差为 0.00021；均为三位时为 0.0021。

交易日历来自源数据披露数量推断，不是逐基金交易日历认证。上述覆盖率、幅度及舍入阈值均为研究中的保守规则，不是基金事件的法定或官方判定标准。低频披露、境外市场日历、历史分红与折算混合口径也可能触发标记。

端点过旧阈值沿用：control 基准和终点离对应月末超过 7 个自然日；shock 基准离窗口前最后推断交易日超过 7 日，终点离窗口最后推断交易日超过 3 日。前月净值引用与源记录偏差超过 0.001 会记录问题。所有这些普通基金质量问题在本版均作为标记保留，不遮蔽可计算值。

## 平台与解释

01/02 默认读取标注版并设置 `APPLY_NAV_QUALITY_SCREEN=False`。改为 True 可恢复上一版较严格样本作敏感性比较。旧补丁应用代码已从 01 删除；原有用户层面的完整 12 月、持仓覆盖率等要求不变。没有上传或运行平台回归。

默认模式会包括带币种、日期、幅度及事件标记的可计算普通基金收益，不能把“样本恢复”解读为“问题修复”。例如 159925 在 2024-01 的份额合并导致单位净值增长超过 80%，该值现在保留并标记，它不是实际财富增长。带币种标记的原币收益没有做人民币汇率换算。使用主结果时应保留这些限定，必要时与严格筛查结果比较。
