## 当前显示规则

- 用等宽空格对齐列，不输出行号、面板编号或竖线。列宽最多24字符；长标签换行，不截断。宽表分为窄面板，重复开头的样本/变量/模型等标识列用于关联。
- 每10条记录重复表头；表格之间加一行分隔线。平台调用仍最多40条结果加1条标题，05扩展报告最多38条加标题。
- 同一调用中内容相同的行增加不同数量的不可见尾部空格，使`Series.unique`保留重复数据和表头；尾部空格纳入容量预检。每次调用重置去重计数，不在屏幕上显示防重编号。
- `Y1`等在结果表中展开为`exp_*`变量名；模型显示Wave、Cell、Controls或No controls。平衡特征代码展开为Age、Education、Gender等标签，原代码字典仍输出。
- 系数和标准误合为`Estimate (SE)`，如`1.756** (0.7324)`；p值独立保留。星号按原始p值严格小于.10/.05/.01，NA不加星。原始和标准化平衡数据保持各自单位，不互相替换。
- 保留原有四位有效数字、所有数值字段、异常状态及置信区间（原表已有时）。空状态用`--`显示；NA仍表示不可用。
- 使用平台已支持的`ant_print_all(..., model_method="unique")`，没有假定支持HTML或Markdown渲染。NumPy文本行宽设为110，减少多个完整数据行挤在同一行；实际平台渲染仍需回传验证。
- 保留每Cell 44KB预算和调用开销预检；超预算明确阻断，不静默截断。不得通过删去不显著结果来减小报告。
