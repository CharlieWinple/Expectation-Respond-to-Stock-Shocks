运行标题：`雇员第二轮 身份口径与识别可行性检验`

原脚本 `scripts/diagnostics/03_employee_diagnostics.py` 已覆盖为
`employee_round2_v1`，共 **10 个 CELL**。新建完整工作流，按标记逐 cell
粘贴、顺序运行；不要只替换原第 8 cell。不需要新增上传表，不写中间表。
在线结果只验证模拟执行；完整提交审核后，将后台 PDF 中

## 固定口径

- v1 明确非经营者，且 v2 明确小微雇员 **或** v3 表示“我在工作”。
  不要求两题同时回答，不用 v9、工资、预期非空定义身份；两路径冲突仅报告。
  这是研究操作口径，不能据此断言全部受访者在法律/劳动关系意义上都是雇员。
- 问卷不是雇主/雇员专属抽样框。样本结论仅适用于平台受访者及所需持仓完整者。
- 不设时长门槛。完全相同行去重，重复用户/提交键冲突排除，缺提交 ID 不单独排除。
- 五波均报告身份、时间、持仓漏斗；识别检验限 2024q3–2025q2 正持仓样本。
  q2 预期时域/利率含义不同，不合并，也不作 q3 的事前预期；q2 的已测量个人特征
  可用于 q3 事前特征检验。
- 逐波精确匹配预期选项；未知/缺失不赋零。出现未映射标签时阻断该波该项的
  数值与回答选择检验并输出选项供核查。区间中点及开口端代表值是工作编码假设，
  正式回归仍需报告端点敏感性。股票 q3 和后续波次使用不同区间字典。

## 组合构造和分组

持仓、冲击和历史输入沿用第一轮三个来源。原始有效非负持仓金额为分母，
未匹配不作零。正持仓要求冲击和 12 个月历史基金覆盖均 >=0.999999。
冲击开始月之前连续 12 个月，按固定期初持仓权重计算月组合收益，再取均值及
样本标准差；不把单只基金波动率加权当成组合波动率。收益使用 flags-only NAV。
被动收益单位为万元：`sum(amount * shock_ret_rate_pp) / 1,000,000`。
仅严格晚于冲击结束日的回答进入检验。

分组参考样本为每波通过数据要求的**非经营者**，在雇员身份、当前预期和
事前信息筛选前一次固定。按 log(金额)、历史风险、历史均值的平均百分位秩
分 3/3/3 档；相同值不拆开，空档允许存在。波次进入组标签。
5/3/3 只作变异对照，不按显著性挑选。多项式尺度使用四波非经营者参考样本，
不因目标/缺失而重算。这里的参考样本选择服务于同一框架内的身份选择检查，
不是沿用雇主样本的 10/3/3 主规格。

## 检验与输出

1. 身份四格、重复键、逐预期编码、职业/教育/工资选项、时长和完整样本漏斗。
   另报四波合计观测数与不重复雇员人数，不能混用。
2. 25 行冲击变异表：合并及四个单波 BASE 的 C/F 与替代分组 C（15 行），
   五个实际有效预期样本的 C/F（10 行）。报告剩余 SD、平方和保留比例、
   最大单条及前 1% 观测贡献、单例组和剩余自由度。
3. BASE 剩余变异的波次贡献；每波基金平均权重最大值、前五份额、HHI 和
   最大基金覆盖用户占比。共同基金相关性仅诊断，尚未实现共同基金冲击标准误。
4. 最多 28 个辅助回归：3 项上一期特征（年龄、大学及以上含大专、v2 路径）、
   5 项上一期自身预期、5 项当前明确作答指示、1 项当前雇员身份，各 C/F 两层。
   不估计当前预期对被动收益的正式效果回归。

C 为固定组合组效应；F 为 C 加逐波组合三项线性控制、六项平方/交乘及持仓万元。
事前变量仅取紧邻上一计划波、身份符合雇员、唯一且答题日严格早于本次冲击的
回答，无回填、无当前特征替代。各目标单独完整样本，C/F 使用同样本。
明确作答指标 1=可数值映射，0=缺失或已识别的不确定类，编码阻断则缺失。
身份选择只考察上一期雇员且当前为非经营者受访者的持仓完整子样本；
不能识别失访、转为经营者或无持仓者的退出。

回归为“辅助目标对当前被动收益”的条件关联。输出 beta/SE/95%CI/p/Holm、
样本量、用户数、目标缺失数、样本内标准化斜率和跳过原因。标准化斜率以各自
检验样本 SD 计算，不能当作全样本共同尺度。用户聚类 CR1，SVD 按实际秩调整
自由度，正态近似推断；最少 50 条、30 用户只是计算门槛，不是统计功效保证。
Holm 按 family/model 分别对 3、5、5、1 个预定目标校正，不跨全部规格保护。
被吸收/不可识别/小样本明确跳过，不作为通过。没有“所有 p>0.05 即可正式回归”的规则。

输出仅聚合，不打印 ID/自由文本。选项每波每项最多 20 类，溢出提示 ISSUES；
每行序号保留，列名与长行折行。禁止 try/except/finally、raise 和普通 print；
所有读表指定 cols、所有合并指定 validate。平台读表错误需修正后重跑完整流程。
