# 05 雇员全持仓正式分析

运行标题为 **小微雇员全持仓：五项预期、三规格回归与同期特征平衡**。在新会话把
`scripts/analysis/05_sme_employee_formal.py` 的 Cells 1–13 分别贴入平台，依次运行并完整提交。
使用 04 已有的 SME 问卷、持仓、画像、冲击和月度收益表。最后四个 cell 分批输出报告。
核对版本 `sme_employee_formal_v1`、STATUS、blocking issues、四个输出块与 REPORT COMPLETE。

主样本为 2024q3 至 2025q2 合并的当期受访者。v1 自报非小微经营者，且 v2 明示小微雇员或
v3 表示在工作，即进入雇员身份口径。采用 04 的时长条件（至少 180 秒，缺失保留）、
用户波次唯一性、冲击后作答、持仓覆盖与用户聚类推断。雇员 2024q2 题目的预期期限或含义不同，
五项回归使用 2024q3、2024q4、2025q1、2025q2。

有持仓记录且为零、持仓表中未匹配这两类分别计数，被动收益均赋零，进入当波独立零组。
未匹配是建模约定。正持仓按合格雇员在当波的持仓金额、历史波动和历史均值分为 10×3×3，
先固定分组再筛选结果和控制变量。收益以万元计。
