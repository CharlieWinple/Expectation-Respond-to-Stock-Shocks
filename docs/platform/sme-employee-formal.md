# 05 雇员全持仓正式分析

运行标题为 **小微雇员五波全持仓100秒：五项预期、三规格回归与同期特征平衡**。在新会话把
`scripts/analysis/05_sme_employee_formal.py` 的 Cells 1–13 分别贴入平台，依次运行并完整提交。
使用 04 已有的 SME 问卷、持仓、画像、冲击和月度收益表。最后四个 cell 分批输出报告。
核对版本 `sme_employee_formal_v2`、STATUS、blocking issues、四个输出块与 REPORT COMPLETE。

主样本为 2024q2 至 2025q2 合并的当期受访者。v1 自报非小微经营者，且 v2 明示小微雇员或
v3 表示在工作，即进入雇员身份口径。采用用户于2026-11-05确认的时长条件（至少100秒，含下限，缺失保留；04经营者为180秒）、
用户波次唯一性、冲击后作答、持仓覆盖与用户聚类推断。2024q2四项宏观预期改用与04相同的 `sme_id3_2024q2_addExpectation`，按submit_id匹配，使用相同编码和逐题冲突处理；不回填原问卷年度/方向题。GDP、房价、物价、利率使用五波，股票仍为后四波。报告单列q2雇员匹配及各题有效数量；真实覆盖待平台返回确认。

有持仓记录且为零、持仓表中未匹配这两类分别计数，被动收益均赋零，进入当波独立零组。
未匹配是建模约定。正持仓按合格雇员在当波的持仓金额、历史波动和历史均值分为 10×3×3，
先固定分组再筛选结果和控制变量。收益以万元计。

雇员控制为年龄、专科及以上、性别类别和城市层级。教育与04采用相同明确标签，混合或未识别标签保留缺失并报告，不再按首项推定专科；年龄与04一样数值化，不另设雇员16—100岁门槛。
利率按雇员问卷的选项区间编码，股票按相应波次的指数点位区间编码。共同样本逐题确定。
与当前04对齐，不做逐波省略、分波持仓平衡或尾部删除。平台报告返回后才据此填写雇员版 Notes 的样本量、系数和图表。

## 与04对齐后的保留差异

- 身份：05为非经营者且(v2明确雇员或v3工作)，04为明确经营者；时长分别100/180秒。
- 结果：05五项预期，04另有六项经营预期；各自问卷v-code和后四波选项字典按实际题目保留，不套用经营者字段。相同选项代表值一致。
- 控制及平衡对象：05年龄、教育、性别、城市；04还含企业年龄、公司制、行业及员工人数补充检验。
- 同期特征，不要求上一波受访；个人画像不宣称每波重新测量。分别在各自合格样本构建10×3×3 cell，边界不跨群体共享。
- 相同持仓收益聚合、历史覆盖、全持仓零组规则、逐题共同样本三规格、用户聚类CR1和原始p、Funnel及四个最终报告cell。05增加身份路径和q2雇员补充表覆盖审计。
