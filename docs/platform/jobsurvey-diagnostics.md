# Jobsurvey 补充诊断

当前脚本：`scripts/diagnostics/07_jobsurvey_diagnostics.py`，版本 `jobsurvey_diagnostic_v7_supplement`。2026-11-16 本地更新，待平台回传。上次全面诊断见11161040及本地已保存的选项mapping；本次不重复全面诊断。

## 本次运行内容

1. 每波RAW、身份键有效、唯一问卷的提交时间范围、有效日期数、缺失/解析失败、季度外日期；日期分位数、逐日人数/累计比例、去重保留人数、日期间隔、每日时长质量。
2. 以RAW首份问卷所在月份为锚，分别取上月末、上上月末持仓，收益期为持仓次日至首份提交前一天。检查最早日期是否被去重或身份键筛选排除。任何日期未解析都会阻断候选诊断，不能忽略缺失后认证最早日期；季度外日期需回传后核查。
3. 两套基期快照的月末、缺失、重复用户基金键检查；持仓零/正/非法分类、金额摘要及分箱、两个月末状态转移与金额差。金额差不是passive gain。
4. 每套持仓下控制完整及各目标非空样本分支。年龄16–100且性别、城市、教育非空仅为诊断门槛，非空不等于合法编码。
5. 新收益可用性：合法零持仓gain为零，正持仓gain待新窗口基金收益，非法持仓保持缺失。

## 运行与输出

表名已配置，平台不读取本地文件。四波问卷读取身份键、提交日期、时长、必要基础控制、教育及结果题；持仓读取用户、基金、月末金额、日期。重新做身份键去重是独立运行所必需，不依赖上一轮内存。

共8个Cell：1配置/辅助函数，2读取问卷，3日期及最小入口审计，4候选持仓，5预检并输出第1块，6–7输出第2–3块，8检查完整性。全部聚合数值表，不输出图片或用户标识。

每次最多40条数据行，Cell预算44,000字节且每次调用预留512字节。完整报告不截断；若真实报告超过3块，按末尾提示将 `report_page(3)` 等续块各放入独立Cell，最后另运行 `report_completion()`。只有全部输出才出现REPORT COMPLETE。

有效快照下用户无记录与记录零均计零；整个月快照不存在不能推断全体为零。正持仓收益暂不构造，需先回传提交日期，再生产对应基金收益并核实净值端点。

本地语法和四波合成测试通过：日期严格解析、原始最早记录被筛除、非法日期阻断、两套月末、持仓重复阻断、零持仓及收益待计算、输出预算与完整性。合成报告2块；真实报告容量和数值以平台回传为准。
