   大专及以上=1。这是明确保留的分类假设，不是对混合文字含义的独立确认。
   同时检验 `pre_college_exclude_mixed`，将该类别置缺失作对照。
   各波报告教育空值、拒答、混合类别、未知标签及映射数；未知标签阻断该波college，
   “不便透露”仍为缺失。其他预期和组合字段不因此删除。
2. 保留原28项辅助检验，重算教育和平衡族Holm，加2项教育排除对照，共最多30项。
3. 对五项当期预期、事前CPI预期和当期雇员身份分别输出C/F基线及敏感性回归，
   共7目标 × 2模型 × 9情景 = **126行**。总计最多156个回归，不按显著性筛选。
   辅助表与敏感性表重复的事前CPI/身份基线用于核对；其原始系数/SE/p应相同。
4. 不再重复已存档的80行职业/学历/工资字典，只输出教育审计及未知选项。

## 固定样本和模型

保持用户确认的非经营者中 v2 明示雇员 OR v3 工作；不加工资、v9或时长门槛。
后四波正持仓、冲击/历史完整、回答严格晚于窗口；q2预期不合并、不作q3事前预期。
固定非经营者参考样本上的wave × 3/3/3分组和控制变量尺度，不因删样本重排。
C=分组固定效应，F=C加逐波组合历史均值、风险、log金额的线性/平方/交叉项及金额。
回归中的被动收益仍为万元，不改成收益率。现有用户聚类CR1和正态CI不变，
共同基金/共同市场因子相关性尚未修正；不得把当前结果直接解释成已识别因果效应。

每个目标先固定其自身非缺失样本；C/F原始样本相同，不要求同时拥有全部五项预期。
事前CPI只取紧邻上一期严格早于冲击的雇员回答；身份检验仍局限于上一期雇员、
当前非经营者受访且持仓完整者，不覆盖失访或转经营者。

## 九个预定情景

| 情景 | 规则 |
|---|---|
| base | 目标完整样本原始估计 |
| capital_1pct | 剔除高于波内雇员BASE期初金额99分位的观测，边界相等保留 |
| residual_1pct | 原目标/模型样本内，剔除剩余冲击平方最大的ceil(1% × N)条 |
| user_1 | 剔除原目标/模型样本中剩余冲击平方合计最大的用户的全部波次 |
| user_2 | 单独剔除原排名第二用户的全部波次，不是在user_1后累计删除 |
| omit_2024q3 | 剔除该波并重估 |
| omit_2024q4 | 剔除该波并重估 |
| omit_2025q1 | 剔除该波并重估 |
| omit_2025q2 | 剔除该波并重估 |

金额门槛在雇员BASE上于目标筛选前一次计算，所有模型/目标共享；身份选择目标
也用同一门槛，它不是身份子样本自身的99分位。残差与用户排名不依赖Y数值，
但依赖目标可观测样本和C/F模型。所有排名在原样本一次固定，不递归删除；
并列按波次/用户稳定排序处理，不输出ID。原冲击没有可辨识剩余变异时不任意删人。

每个情景真正重新估计分组效应、连续控制、系数和用户聚类标准误；
保存N/用户数、删除数、消失组数、删去的原始剩余平方和份额、beta/SE/CI/p/Holm，
以及重估后的剩余SD、前1%和最大单条贡献。`NO_CHANGE`标记没有删去观测，
例如事前CPI样本本来不含q3，省略q3不能当作新增稳健性证据。
金额门槛缺失明确标为不可用，不据此删掉整波。小样本/被吸收/无自由度均跳过并报告。

敏感性表的标准化系数固定使用每个目标原样本的gain SD / Y SD，
不因删除重算；原辅助表仍是各检验自身SD。不同目标不共享尺度。
敏感性表Holm按每模型/情景的五个当期预期一族、两个重点识别目标一族计算，
不可用项按p=1占位但不打印虚假p。辅助表维持原族3/5/5/1，教育排除另为单项族。
因此重点基线的Holm可以与辅助表不同；不保护跨情景/跨模型挑选结果。

## 本地检查与结果解释

本地语法检查及合成数据测试覆盖实际混合学历、拒答、未知教育阻断、
五波完整流程、删除整用户、固定删除规则、空波省略，以及删除后C/F回归。
独立虚拟变量OLS核对系数和聚类SE，而不是复用同一估计函数作为“正确答案”。
本地测试不是平台结果；待本轮报告返回再评估教育修复、q4影响点、身份选择
及各预期主结果的稳定性。不预设所有p值不显著才可进入下一步。
