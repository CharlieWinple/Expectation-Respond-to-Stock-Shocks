# 经营者与雇员答题时长诊断

运行标题为 **小微经营者与雇员答题时长、作答质量及门槛损失诊断**。
将 `scripts/diagnostics/06_sme_duration_diagnostics.py` 的 12 个标记块依次放入独立平台会话。
使用 04/05 的问卷、画像、基金持仓、冲击、历史收益和经营者 2024q2 补充表。最终四个 cell 只打印汇总绘图数据和诊断表。

- `common4` 为两类人共同的 2024q3–2025q2，`formal5` 为含 2024q2 的经营者样本。两种范围重叠，分别解读。
- A 从全部问卷判定用户波次唯一后，保留有用户键且符合当期身份的回答。B 再要求冲击后提交、全持仓规则、收益和构造 cell 的历史覆盖。记录零和未匹配置零按正式口径保留。controls 在 B 上加各人群正式控制完整条件；各预期再加该题有效编码。
- 时长采用正式脚本的解析方式，多值取最后一个可解析值，另报多值和含时长字段但解析失败的数量。0/60/120/180 秒模拟均含下限、均保留时长缺失；0 对应无时长筛选。按用户计的损失指该范围内所有合格记录均被剔除的人。
- 本地画时长分布时按 `hist` 的 role、scope、sample 分面，使用 `lo/hi/N/timed/share/cum_share`。每个区间左闭右开；`cum_share` 对应上界之前的累计比例，最后一箱开放。非等宽箱用分组柱图，或按箱宽转换密度并单列开放箱。缺失单列在 `quantiles`。分波及路径的粗时长分布可用 `quality` 每组 N。
- `quality` 记录三个基础题的空白项数及分母。经营者选开业年份、注册类型、行业；雇员选工作性质、工资和工时。是核心字段完整性代理，实际展示日志不可见。异常计数为出现任一预设矛盾的记录：经营者有雇员工资题回答，2024q4经营者出现多个版本学历字段，或 v2 明示雇员同时在 v3 填非工作状态。编码或跳转也可能导致异常。重复/身份冲突在去重前另报。`items` 在共同四波分别列五个宏观预期的数值回答、不确定、空白或未展示、其他。经营者宏观模块可能随机或分支展示，空白列不能直接用于判定缺答。
- `differences` 报相邻时长组的基础题空白率或异常人次率之差（短组减长组，百分点），附用户聚类 SE 和 95% 正态区间。调整列吸收波次×可识别路径，仅在两组均出现的层内估计。雇员用 v2/v3 路径，2024q4 经营者用三列学历的非空位置代理版本，未知或多列非空单列。时长缺失只作描述。
- `retention` 与 `composition` 报 B 样本各特征组保留率、保留者特征和持仓构成；`loss` 按 A、B、控制完整及各题实际样本报告基准与保留的人次、人数及差。对照此前平台报告时，确认人群、波次、时长与筛选顺序一致。

核对开头状态、issues、四个分块及结束标记。门槛比较用于评估质量和样本选择，不按时长组自动标注无效卷。本地合成结果仅验证流程。
