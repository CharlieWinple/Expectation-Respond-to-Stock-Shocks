# 雇员第一轮平台诊断

脚本：`scripts/diagnostics/03_employee_diagnostics.py`
版本：`employee_round1_v1`。共 8 个 CELL，独立运行，不依赖脚本 01/02。

## 运行

1. 新建平台工作流，按 CELL 1–8 标记分别粘贴、顺序执行。
2. Cell 2 默认读五波问卷、现有持仓表及
   `shock_panel_nav_annotated_v1`、`ctrl_monthly_nav_annotated_v1`。
   核实侧栏表名即可，不需要新增上传表。保留默认空的
   `CONFIRMED_EMPLOYEE_ANSWERS`，待返回身份选项后再决定。
3. 在线运行仅验证模拟环境；完整工作流成功后提交审核，由后台运行真实数据。
4. 返回 Cell 8 的 `EMPLOYEE ROUND1 REPORT BEGIN` 到 `END` 完整报告，
   包含末尾 ISSUES。建议标题：`雇员第一轮 问卷与持仓覆盖诊断`。

不估计回归、不写中间表、不打印用户 ID、提交 ID、自由文本或 extro_info。
只使用 ant_read_data / ant_print_all；读取指定 cols，所有 merge 有 validate。

## 样本与指标含义

- mapping 来自 `data/小微调研变量映射表.xlsx`。雇员预期按五波分别指定。
  q2 为年度预测、利率方向题，无股票预期字段；不读雇主 addon、不补值。
- 身份选项尚未确认。候选样本是“不是已知经营者答案，且雇员工资、工作性质、
  雇员预期至少一项非空”。该代理依赖回答完整性，可能漏掉全部未回答者，
  也可能纳入身份异常者，不能称为最终雇员／在职样本。v1 分组交叉汇总覆盖所有回答。
- 选项和候选特征覆盖基于完全相同选定行去重后的记录；时间、持仓、预期筛选
  基于具有唯一用户回答和唯一非空提交 ID 的候选记录。缺失提交 ID 不单独排除。
  多个非完全相同行属于同一用户时，整组暂不进入筛选，不擅自保留首行。
- 不设答题时长排除门槛，报告 p10/p50/p90、低于 60/120/180 秒的数量。
  answerSeconds 使用既有分号键值格式；无匹配或多次匹配记缺失，并报告多次匹配。
- 日期按自然日处理，回答必须严格晚于冲击结束日；快照必须严格早于冲击开始日。
  日期解析失败不使用替代日期；提交超过窗口结束 30 天只报告，不排除。
- 持仓分母为所有有效非负期初基金金额。正持仓、记录零、未匹配、无效分别报告。
  非法金额、负数、缺基金代码或冲突用户—基金键使该用户持仓无效，不删掉坏行后继续加总。
  持仓无法定位日期／用户则阻断覆盖判断；相关月出现非月末记录也阻断该波覆盖。
- 冲击覆盖要求收益有限且 shock_usable=1。历史覆盖为有完整 12 个指定月份
  收益的基金金额占原始组合金额比例。月份为冲击开始月份之前的连续 12 个月。
  两项完整标准均为 >=0.999999。零持仓不定义覆盖率，不把未匹配变成零。
- 采用现有 flags-only NAV 价格收益版本，不额外施加质量标记筛选，不宣称总回报口径。
- 预期只判断非空及“不知道”等中文词的初步识别，不做区间赋值、方向数值化或有效性认证。
  `eligible_nonunknown` 仍不是正式回归样本。blocked 阶段显示 NA，而不是零样本。
- 经营者教育字段的版本审计仅作问卷结构检查，不自动拼接重复字段。

## 输出预算与解释

所有汇总在 Cell 8 输出；每行有稳定 T/R/L 键，避免 unique 去重吃掉重复内容。
v1 最多 20 个组；v2、v3 和每个波次每项预期最多展示 20 个非空选项。
高基数纯数值答案改为分位数汇总，其他超限类别报告遗漏记录数和 ISSUES，
不能据截断字典完成正式编码。超过 100 字符的标签不释放全文。
五波最多 100 行身份组和 700 行选项，实际取决于选项数；不打印逐用户明细。
不同表的分母见标题与上述口径，不能混当正式雇员人数。

不使用平台禁止的 try/except。源表读取直接报错时，当前 cell 会停止，需要修正
表名、字段或权限后重新运行。读取返回 None、返回数据缺列、版本错误、冲突基金键、
无效窗口等通过显式检查记录 ISSUES 并跳过依赖部分。
ISSUES 为空也不代表身份和答案编码已经确认。
